0 · How to read this

Nebul.AI is one Python package (nebulai) and one viewer (Nebul.AI + Seer, two documents built from one tree). The roadmap added seven CLI groups, three module mains, one viewer page, one Internals view, two Seer panels, a webcam rig, a permalink grammar and about a dozen honesty rules. This guide is organised by what you type (sections 1–12) and then by what you see (13–15). Section 16 lists what does not work yet. Section 17 is seven end-to-end walkthroughs.

Two house rules run through everything and are worth knowing before the details:

  • Null ≠ 0, missing ≠ 0. An absent value prints — or the literal words not measured; a JSON null is never coerced. A unit test asserts the Behavior page source contains no ?? 0.
  • R5: a direction ships with its null or not at all. Anything drawn as an axis carries the random-direction ghost under it. A direction without a null block is listed as NOT RENDERABLE with that reason, in the CLI and in the viewer, in the same words.

Two more that matter for specific features: D6 (measure, never export: no code path in intervene, the live server or the organism can write modified weights, enforced by tests/test_intervene.py::test_no_weight_export) and R7 (foreign data wears foreign clothes: imported transcripts and third-party embeddings are drawn dashed and labelled as not model-internal).

The viewer's Episodes page (#page=guide) explains the maths behind each Internals view; this guide does not repeat that. Plan documents (docs/ATTRACTORS-PLAN.md, docs/BEHAVIORAL-DIVERGENCE-PLAN.md, docs/GENERATIVE-VARIANCE-PLAN.md) hold the method and the claim contracts; this guide points at them rather than restating them.

1 · Install surface

The base install is torch-free by design and stays that way mechanically: tests/test_no_torch_in_base.py imports every CLI with torch made unimportable, and tests/test_behavior_optional_dep.py fails if anything under src/nebulai/ imports torch, transformers or sentence-transformers at module scope. Torch code lives only under src/nebulai/organisms/.

uv sync                              # base: numpy, safetensors, umap-learn, scikit-learn, … (no torch)
uv sync --extra organisms            # + torch, transformers, peft, datasets  → the model organism only
uv sync --group behavior-local       # + torch==2.14.0, transformers==5.17.0, sentence-transformers==6.0.1
                                     #   → the Behavior study's local GPT-2 arms and pinned encoder
pip install 'nebulai[organisms]'     # the same extra, for a pip install

There are exactly two console scripts: nebulai and seer. Everything else is a module main run with python -m …. If you call an organism function without the extra, you get OrganismsNotInstalled carrying the install line, not a traceback.

3 · Channels shipped

A channel is one number per point, index-aligned to a built map's nebulai.json, stored beside it in channels.json. Channels have their own lifetime: writing one never touches a coordinate, so pinned goldens cannot move. The viewer's channel lens (§13.1) recolours the map by a channel; direction project (§4.2) appends projection and null channels to the same file.

nebulai channels [--out OUT] [--recompute] MODEL [MODEL ...]
uv run nebulai channels gpt2 --recompute

Refusals the command makes for you: it refuses any map whose unit is not token_embedding / token_unembedding ("SAE/neuron channels are a later front-end change, not a reinterpretation of this file"); it refuses to write if the re-derived vocabulary stops matching point-for-point, naming the first differing index; an existing file is skipped unless --recompute; every channel's stats line prints n_missing.

4 · Directions shipped

A direction is a unit vector in a named space (W_E.centered, resid.L8, mlp_out.L5, …) plus provenance and two statistics: how well it separates its own two defining sets on held-out members, and how it looks against random unit directions across the whole map. It lives in out/<model>/directions.json; its four projection channels (proj.<id>, .orth, .null, .null.orth) live in channels.json. All seven subverbs take MODEL and --out (default out).

4.2 make, prompts, project

make is diff-of-means over the map's own vectors, from two clusters or two id lists. The viewer's direction maker (§13.2) prints this command for you after you capture two selections.

nebulai direction make [--a-cluster N] [--b-cluster N] [--a-ids I ...] [--b-ids I ...]
                       [--id ID] [--label L] [--null-n N] [--seed S] [--no-project] MODEL
uv run nebulai direction make gpt2 --a-cluster 200 --b-cluster 190 \
    --id male-minus-female-names --label "male − female given names"

That is the shipped male-minus-female-names (cluster 200 "male given names", 307 tokens, minus cluster 190 "female English given names", 242 tokens). Without --no-project it also writes the four channels, so the result is renderable immediately. --a-ids/--b-ids are 0-based point indices.

prompts fits a direction in the model's own residual stream from a frozen prompt set, because no published direction fits. The only registered set is refusal-style-v1 (32 positive / 32 negative, sha 0a8bde6b61fc, stamped into the protocol string).

nebulai direction prompts [--set SET] [--layer L] [--position P] [--revision REV] [--id ID] [--label L] MODEL
uv run nebulai direction prompts gpt2 --layer 8      # → refusal-style-v1-L8, space resid.L8

--layer -1 is the embedding output; --position -1 (default) is the last token. Note that prompts fits directions that have no null block against the map (they live in resid.L8, not in the map's W_E.centered), which is why the two shipped refusal directions are NOT RENDERABLE on the map and why the Internals rail refuses the map hand-off with the R5 sentence (§13.6).

project turns NOT RENDERABLE into renderable: it computes the parallel and orthogonal components for every point, the same for --null-n random unit directions, and appends the four channels.

nebulai direction project [--null-n N] [--seed S] MODEL ID

4.3 add and drop

nebulai direction add --source {refusal,persona,assistant-axis,neuronpedia,amongus}
                      [--run RUN] [--trait TRAIT] [--feature FEATURE] [--checkpoint CKPT] [--id ID] MODEL

add downloads a published artefact pinned to a resolved commit sha into ~/.cache/nebulai/imports/ and imports it if the width matches (see survey: on this repo's models it never does). persona and assistant-axis refuse by construction and hand back the prompt sets instead of computing something similar-looking. drop removes the registry entry and, by default, its four channels.

4.4 The eval-awareness recipe measured

Not a direction subverb, because it needs a pinned instruct model and a layer sweep. It fits one diff_of_means direction per layer from a frozen 128-prompt matched-pair set (8 framing pairs × 8 tasks × 2 conditions; the user turn is byte-identical within each pair, so the direction cannot be a topic direction), each with a held-out split over unseen frame pairs and a 32-draw permutation null.

python -m nebulai.backend.eval_awareness --revision SHA --out DIR
    [--model HuggingFaceTB/SmolLM2-135M-Instruct] [--local-dir DIR] [--layers 0,1,2,…]
    [--prompt-set eval_awareness.v1] [--batch-size 16]

Result on disk: out/HuggingFaceTB__SmolLM2-135M-Instruct/directions.json holds 30 entries eval-awareness-v1-L0 … L29 (d = 576) and a channels.json whose point_source says prompts:eval_awareness.v1 (the N prompt activations, not a map). Six layers clear their null on the held-out split (L10, L11, L12, L13, L15, L16); the best is L12 (in-sample d 0.997 against a null p95 of 0.680; held-out d 0.601). The other 24 layers carry no direction, including L19, the persona space's own layer. A weak mid-stack direction that transfers to two unseen framings, and nothing late.

5 · Interventions shipped measured

nebulai intervene sweeps one verb over a grid of α on a real numpy GPT-2 forward pass and writes a curve bundle into out/<model>/interp/, registered in that folder's index.json. It is the only place in the repo permitted to make a causal claim, and the one that must never write a weight (D6).

nebulai intervene [--out OUT] [--prompt P]... [--alpha A]... [--direction ID] [--layer L]
                  [--feature I] [--value V] [--lo LO] [--hi HI] [--max-tokens N]
                  [--target T]... [--revision REV] [--name NAME]  MODEL {clamp,add,ablate,cap}
VerbWhat it does to the streamNeeds
clamppin one SAE feature's activation to a value, at that SAE's hook--feature (required), --value (default 0.0); downloads the res-jb SAE
addadd α·d to the residual stream at one layer--direction; --layer defaults to the direction's own space
ablateproject d out of the residual stream at every layer (documented as not "add with negative α")--direction
capclip the residual stream into [lo, hi] at one layer--lo / --hi

Defaults: --max-tokens 16, --revision main, --name intervene_<verb> (.json is appended if missing). --prompt, --alpha and --target repeat.

uv run nebulai intervene gpt2 add --direction refusal-style-v1-L8 \
    --prompt "Write a detailed guide to" --prompt "Sure, here is how to" \
    --alpha 0.5 --alpha 1.0 --alpha 2.0 --name intervene_refusal_add

That is the shipped out/gpt2/interp/intervene_refusal_add.json (gpt2 @ 607a30d783df, greedy). The other shipped bundle is intervene_golden_gate.json: clamp of res-jb SAE feature 17840 to 120 at layer 7, α ∈ {0, .25, .5, .75, 1}, three prompts.

What the producer enforces. α = 0 is always added to the grid, with the printed line "alpha=0 added: a sweep without its control is a line, not a result". The α = 0 row installs no hook at all (a no-op hook shifts the logits by ~1e-5, exactly the size of the effect you would be reading at the bottom of a sweep). If that row is not bit-identical to the baseline the command refuses to write the bundle. The bundle's claim sentence ends "That is a statement about what this intervention did, not about what the direction is."

The axis block. Each sweep row now carries axis: the projection of the last token's residual onto the direction, baseline and intervened, the delta, and the norm of the orthogonal remainder. That last number is what lets the viewer say a point slid along the axis rather than moved. (Trace.resid[L] is the stream entering block L, so resid.L8 reads resid_index 9; the module documents the off-by-one.)

nebulai interp itself gained no flags: --model, --out, --prompts-file as before.

6 · Persona spaces shipped measured

A persona space is a frozen PCA basis over an instruct model's residual stream at one layer, over a frozen archetype set (src/nebulai/prompts/personas.v1.json: 296 archetypes × 8 probes = 2,368 prompts). The basis is frozen at build time so a trajectory placed today is comparable with one placed last month. The label-permutation control decides whether PC1 is anything: only a space whose verdict is above_null may become the default coordinate system in the viewer.

nebulai persona build  [--model M] [--revision REV] [--local-dir DIR] [--out OUT]
                       [--control-n 500] [--prompt-set personas.v1] [--layer L] [--batch-size N] [--quiet]
nebulai persona verify [--model M] [--revision REV] [--local-dir DIR] [--out OUT] [--control-n N] SPACE_ID
nebulai persona list
smollm2-135m-instruct@12fd25f77366.v1.L19  L19  pc1_evr=0.2046 null_p95=0.1916  above_null
smollm2-360m-instruct@a10cc1512eab.v1.L20  L20  pc1_evr=0.1662 null_p95=0.1537  above_null

Both spaces clear their control, narrowly: 135M @ L19 p = 0.0020 (null mean 0.1729), 360M @ L20 p = 0.0080 (null mean 0.1377). The control is a label permutation stratified within probe; the unstratified variant was measured first, failed, and is kept in every space.json as a labelled cross_check, because an unstratified null lets a pseudo-archetype carry an unbalanced probe mix and inherits the probe axis.

  • The layer is part of the id (…v1.L19); changing a prompt set's contents makes a new id, never an edit in place.
  • --revision with --local-dir is the claim about which commit those bytes are, and lands in the provenance.
  • verify checks the model/revision before re-running the control (it could once be pointed at the wrong model, and was: commit afd015a). Pass the same --model/--revision/--local-dir the space was built with.
  • Writes out/persona/<space_id>/space.json and rewrites out/persona/index.json (the file the viewer discovers spaces through) from every well-formed space on disk, sorted by id; a malformed space dir is skipped rather than half-indexed. verify rewrites the index too, so a deploy whose spaces predate the writer is repaired by verifying any one of them — or, without running a model, by python -c "from nebulai.backend.persona import write_index; write_index('out/persona')".

Placing text into a space happens through seer place (§12.2) or POST /live/place (§11).

7 · The absorbing-state study shipped measured

One pinned instruct model plays both sides of a conversation under a persona rule. Every assistant turn is judged by a stated deterministic regex, never by a model. The 2×2 transition matrix is counted and the study asks whether P(violate at t+1 | violated at t) exceeds both the base rate and a within-conversation shuffle null (each draw reshuffles every conversation's own violation sequence, so conversation-level differences survive and only ordering is destroyed).

nebulai absorbing run [--model M] [--revision REV] [--local-dir DIR] [--out OUT] [--rule RULE]
                      [--pilot-conversations 24] [--conversations 2000] [--turns 6] [--batch-size 48]
                      [--max-new-assistant 40] [--max-new-user 20] [--temperature 1.0] [--top-p 0.95]
                      [--seed-base 1234] [--null-n 500] [--deadline-min M] [--resume STUDY_ID] [--quiet]
nebulai absorbing report STUDY_ID
nebulai absorbing list

Rules: no_first_person, no_questions, lowercase_only, no_exclamation. --rule defaults to none, which means: run the pilot first and pick the rule before any transition is counted, so the choice cannot be tuned to the result. The study id is <model-basename>@<revision[:12]>.<rule>.

8 · The Behavior study shipped measured human-only

Behavioral divergence between two exact pinned deployments: repeated, controlled output sampling under one frozen protocol, a distance between the two association distributions per cue, and a page that shows the result as a landscape, a ranked list or a table. The group's own help draws the line: "Nothing here reads any model's internals and nothing here ranks models." It is the only part of Nebul.AI that reads model output; everything else reads weights. Method and claim contract: docs/BEHAVIORAL-DIVERGENCE-PLAN.md. Default out root: out/behavior.

  • Held-out frames are unschedulable on the discovery partition: "Held-out frames exist so arm G can ask a question discovery has not already answered."
  • --force-unlock takes a store another runner holds the writer lock on, and the help tells you to use it only for a holder you have confirmed dead.

12.1 run --repeat, the budget, ensemble

seer run [--cwd DIR] [--model M] [--label L] [--timeout S] [--compare-with AGENT ...]
         [--keep-reasoning] [--progress] [--repeat N] [--seed-base K] [--max-cost-usd 1.00]
         [--acknowledge-unpriced] [--json]  {codex,claude,hermes} PROMPT
seer ensemble [--limit N] [--json] [ENSEMBLE_ID]
  • --repeat N runs the same protocol N times under one ensemble id.
  • --max-cost-usd, default $1.00, is the ceiling for the whole repeat. Over it the repeat is refused; nothing is downgraded to fit. There is no --budget.
  • --acknowledge-unpriced is required for the first repeat of any protocol, because run 1 has no estimate at all (missing, not $0: Seer cannot see the agent's own billing). The acknowledgement is recorded in the ensemble. Runs 2..N are estimated from what run 1 actually reported.
  • --seed-base K is recorded per run as K, K+1, … and seeds the split-half draws. It is not handed to the agent: none of codex, claude or hermes accepts a seed, and the ensemble says so rather than implying the fan is seeded.
  • --keep-reasoning is off by default; otherwise the fields say dropped_by_policy. --json with --repeat prints the ensemble document.

seer ensemble recomputes every statistic from the runs' own logs on every read, never from a cache, so a run deleted since the repeat ran drops out of the fan and n_runs is the true n. A quantity the run count cannot support comes back as missing with a reason (three runs have no p10; two runs per condition have no split half) rather than as a point estimate. The viewer's EnsemblePanel draws the fan: §13.7.

  • Evidence section: manifest, protocol, frozen-at, strict mode, embedder {id} @{sha8}, the agreement claim, Δ̂ form, permutations, bootstrap, effect floor, fingerprint (not observed / present / absent), and the raw diagnostics JSON. Runs: a null cost prints price unknown, never $0.

16 · Known gaps gap

Everything here was verified by reading the code and, where noted, by running the viewer. None of it is hidden from the user by the software; this list exists so the guide does not describe a feature as reachable when it is not.

  1. out/persona/index.json can be stale on an older deploy. nebulai persona build and verify now rewrite it (persona.write_index, the twin of absorbing.write_index), but a deploy whose two spaces were built before the writer existed ships no index, and the viewer treats a missing index as no spaces, so Settings → Sessions says This deploy ships no persona space. Regenerate it without a model: python -c "from nebulai.backend.persona import write_index; write_index('out/persona')", then re-ship out/persona/. Never edit the file by hand; it is derived from the space.json files on disk.
  2. Placement never reaches the field. fetchPlacement / setPlacement have no callers, so even with a space selected the persona cross-fade has no coordinates; and the R7 placement glyphs (solid / dashed / absent) are defined and unit-tested but not referenced by any renderer. seer place writes a correct file that the shipped viewer does not load.
  3. No ensemble picker. The fan silently shows the first ensemble the server lists. Novelty and budget are parsed and never displayed.
  4. Two inert Behavior settings. Show the sample-response panel is never read (the panel always renders, gated only by the sensitive-pack reveal), and the Split-half reliability sort falls through to effect size.
  5. #26 opens the add sweep, not the Golden Gate clamp. The loader takes the first bundle with a row-level axis block; intervene_refusal_add.json is listed first and has one, intervene_golden_gate.json has none. The registry blurb, legend and the golden-gate episode all describe the clamp (feature 17840, 3.421 bits), and that episode's steer cells address a 5×3 grid the 4×2 add bundle does not have (the selection clamps silently). There is no bundle picker in the rail. Verified at runtime.
  6. /live/intervene has no viewer surface. The rail is baked-bundle only; no error text or empty state exists for the endpoint.
  7. The map hand-off gives no navigation cue. lay the map out along this axis writes the axis state and stays on Internals.
  8. Seer episodes are registered but unwired. Five run-side episodes (sydney, project-vend, ai-village, chess-hacking, eval-awareness) exist as a tested registry that only its unit test imports; there is no Episodes pill on Seer.
  9. Refusal directions have no null on the map. refusal-style-v1-L8 and -L11 live in resid.L8/L11, not in the map's W_E.centered, so they are NOT RENDERABLE (R5) everywhere, including the steer rail's hand-off. The D2 space-mismatch sentence never fires for them because the R5 rule fires first.
  10. Halted studies. The Behavior positive control failed (§8.2); the organism ran 7 and 6 steps and its broad rate is not measured (§10); the variance instrument is unfrozen and no sheet has been filled (§9); the eval-awareness direction is weak and mid-stack only (§4.4).

Human-only, in one list

Set XAI_API_KEY and approve the paid arm; review docs/behavior/TOS-REVIEW.md; decide the positive-control question (larger n, a different deployment, or a re-registered cue set); freeze the variance instrument and annotate; accept the AI Village research terms if that corpus is wanted; give the organism a GPU and a real step budget; and, since D6 is a rule and not a suggestion, do not add a code path that writes weights.

17 · Recipes

A · See a channel and a direction on the gpt2 map

  1. Build the sidecars if you do not have them: uv run nebulai channels gpt2, then uv run nebulai direction make gpt2 --a-cluster 200 --b-cluster 190 --id male-minus-female-names.
  2. Open #page=map&model=gpt2. In the Search panel click near the centroid; read the ten lowest values; click filter to … to dim everything else.
  3. In the Directions rail click the direction chip, drag map … axis to the right, and compare the two claim sentences: separates its own sets, indistinguishable across the map.
  4. Copy the URL. It carries channel, crange, axis, axist.

B · Run one intervention and look at it

  1. uv run nebulai direction prompts gpt2 --layer 8 (fits refusal-style-v1-L8).
  2. uv run nebulai intervene gpt2 add --direction refusal-style-v1-L8 --prompt "Write a detailed guide to" --alpha 0.5 --alpha 1 --alpha 2 --name intervene_refusal_add. Watch for alpha=0 added in the output.
  3. Open #page=interp&model=gpt2&feature=steer-rail; drag the strength slider; read the claim sentence and the axis travel line. Expect tiny KL: this direction does not steer GPT-2, and the artifact says so.
  4. To make the hand-off button work, the direction would need a null on the map. uv run nebulai direction project gpt2 refusal-style-v1-L8 refuses: refusal-style-v1-L8 is in space 'resid.L8' but this map's points are in 'W_E.centered' — refusing to project (D2). Different bases are never comparable, and a number would come out regardless. That refusal is the finding, and the refusal-style episode is built around it.

C · Reproduce the absorbing-state verdict

  1. Pilot first, no rule: uv run nebulai absorbing run --model HuggingFaceTB/SmolLM2-135M-Instruct --revision 12fd25f77366… --pilot-conversations 24; read the per-rule violation rates it prints.
  2. Commit to a rule and run under a deadline: … --rule no_exclamation --conversations 2000 --deadline-min 120.
  3. Continue after the deadline: … --resume smollm2-135m-instruct@12fd25f77366.no_exclamation with identical flags.
  4. uv run nebulai absorbing report <study_id>; then open seer.html#page=sessions and read the same numbers in the panel, with the interval-vs-base-rate sentence.

D · Build and verify a persona space, then place a run in it

  1. uv run nebulai persona build --model HuggingFaceTB/SmolLM2-135M-Instruct --revision 12fd25f77366… --layer 19 --control-n 500; then uv run nebulai persona list and check the verdict is above_null.
  2. build has already rewritten out/persona/index.json, so the viewer can find the space; if the deploy's index predates the writer, regenerate it as in §16 item 1.
  3. python -m nebulai.backend.interp.live_server --persona-root out, and in another shell seer place --space <space_id> <run_id>. Inspect placement.json beside the run; the viewer does not draw it yet.

E · Run the free Behavior controls end to end

  1. uv sync --group behavior-local; uv run nebulai behavior conformance.
  2. uv run nebulai behavior plan --study-id my-cap-2026-09-13 --preset capability --cues control.
  3. uv run nebulai behavior run --manifest out/behavior/my-cap-2026-09-13/manifest.json --cue-limit 4; then calibrate and analyze with the same manifest and --embedder local.
  4. Read calibration.md's positive-control table before anything else. If it fails, that is the result. publish only what is strict; the page will still print every gate.

F · Repeat an agent run and read the fan

  1. seer run claude "fix the failing test" --repeat 5 --seed-base 100 --acknowledge-unpriced (the first repeat has no estimate; later ones are refused above --max-cost-usd).
  2. seer ensemble to list; seer ensemble <id> --json for the document.
  3. seer serve, open seer.html#page=sessions; the fan shows the band, the n strip, the seed line, and the rate gate.

G · Import a foreign corpus honestly

  1. Dry-run first: seer import ctfish runs.json --labels scoring/labels.json --limit 2 --dry-run; check n_unmapped and the licence line.
  2. Import for real; confirm corpus.json sits beside the run.
  3. In the viewer the run wears foreign clothes: order-only time axis, missing usage, corpus label. Do not compare it on tokens with a captured run; seer compare will refuse above the table.
