psychiX

Two instruments for looking inside the work.

One of them maps what a language model has learned; the other maps what an agent did. Both are static, client-side viewers over measurements that were computed ahead of time — nothing is calculated on a server when you open a page, and nothing is invented to fill a gap.

A measurement that is missing is drawn as missing, never as a zero.

nebul.ai map what a model knows

Model cartography. Every token, sparse-autoencoder feature or MLP neuron is placed by the model's own vector for it, reduced to two dimensions, clustered and named — so a model's vocabulary becomes a map you can read.

  • Semantic map the atlas itself, plus chord, hierarchy and A/B compare views
  • Internals panels measured from stored weights and single forward passes
  • Guide what each view measures, the math, and where the numbers came from
Open Nebul.AI↗ seer map what an agent did

Agent observability. A coding agent's run is a long transcript nobody reads; Seer turns one into a shape — tokens, tools, context and cost over time — and refuses to compare two runs on a number their agents do not count the same way.

  • Live a run as it happens, from a capture server you point it at
  • Transcripts drop a session log; it flies as a path through time, context and output
  • Topics which subjects a conversation actually circled, turn by turn
Open Seer↗

Both instruments render in the browser — WebGPU where the device has it, WebGL2 everywhere else. Nebul.AI reads a pre-baked artifact tree served beside it. Seer reads only what you give it: a transcript you drop in, or a capture server you name yourself. Neither sends your data anywhere.
